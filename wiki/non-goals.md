# Non-goals — wat vibe-kit bewust niet is

- **Geen codegeneratie-religie.** Dit is een contract + poorten, geen belofte dat Engels magisch
  naar code compileert. De waarde zit in gedeelde intentie en de goedkeuringspoort.
- **Geen zware ceremonie.** Triviale wijzigingen gaan gewoon door; het proces schaalt mee met de
  wijziging. Over-specificatie schept starheid (onderbouwing: [`docs/WHY.md` §3](../docs/WHY.md)).
- **Geen tweede bron van waarheid.** De wiki beschrijft intentie; de code is de implementatie. Zie
  `rule-een-bron-van-waarheid`.
- **Geen wiki-vooraf-verplichting.** De wiki groeit met het werk mee (zelf-scaffold).
- **Geen framework of runtime-dependency.** De kit is documentatie + één dependency-vrij Node-script.
- **Niet doelgroep niet-technici.** Mikt op technische bouwers met een capabele agent — vandaar
  lichter dan Ismail's originele Product Wiki.
