# Glossary — gedeelde termen

- **Intentie** — *wat* er moet gebeuren en *waarom*. Leeft in de `wiki/`, niet in de code.
- **Unit** — één klein Markdown-bestand in de wiki met een stabiele ID (`rule-`, `cap-`, `dec-`,
  `chk-`) dat één stuk intentie draagt.
- **Voorstel** — beschrijving in gewone taal van een substantiële wijziging, vóór code, die de mens
  goedkeurt. De afstemmingspoort.
- **Poort** — een van de drie vragen (reuse, architectuur, correctheid) die je langsloopt vóór je
  wijzigt.
- **`PW:`-anker** — grep-bare comment in code die naar een wiki-ID linkt (`PW:` = "Product Wiki",
  term overgenomen uit Ismail's origineel).
- **Drift** — het uiteenlopen van code en intentie (duplicatie, verweesde ankers, niet-gedekte
  regels). Bewaakt door de drift-check.
- **Ceremonie** — de hoeveelheid proces rond een wijziging; schaalt mee (triviaal/klein/substantieel).
- **Praktisch determinisme** — niet het model deterministisch maken, maar *wat* het moet produceren
  zo vastpinnen dat er voor het *hoe* weinig improvisatieruimte overblijft.
- **Dogfooding** — vibe-kit past zijn eigen methode toe op zichzelf.
